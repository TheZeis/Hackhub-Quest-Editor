# r271 — Five-scene manual illustration prototype

Zeis approved one shared, offline-capable renderer and chose not to use a game
screenshot. The tutorial's game-only installation image was removed while its
written instructions stayed. The manual then referenced 88 editor figures; no
existing figure had been converted.

The prototype used five scenes built from actual editor components and a fixed
First Contact fixture: an Objective inspector, a wired two-node canvas, the
Settings panel, the full workspace and a mid-drag wire. Later rounds fixed its
offline startup, refined its layout, and added captions and descriptive frame
titles. The user confirmed in Firefox from disk that Tab skips the page and all
five scenes. Screen-reader output remains unverified and lower priority by user
direction.

The r271 proposal and source evidence are in
[`../plans/r271-code-rendered-manual-illustrations.md`](../plans/r271-code-rendered-manual-illustrations.md).
The renderer was not a screenshot and did not replace any of the 88 editor
figures. The editor build stamp remained `2026-10-03.r267`.
