QE24 Dynamic Page Probe 1.0.0 (r238)

What this is
  A QA probe for the SDK 0.24 DYNAMIC website pages - the kind of page that
  is printed on the spot for each visit instead of being one fixed page for
  everyone. It is the test page for the editor's future dynamic-page
  feature; nothing here is player-facing content.

How to run it
  1. Restart the game after installing.
  2. Open Hackhub and accept the "QA probe (r238)" feed post (or claim
     QEDynProbeQuest from the sandbox group).
  3. Work the quest tracker TOP TO BOTTOM. The twelve objectives are the
     checklist in the order to run them; each says what to open and what
     to write down.
  4. Row DP-06 (your first visit to /state) fires the quest's beat
     automatically - keep the row order so DP-05 and DP-08 bracket it.
  5. The site: http://qe24-dyn.test
     Rows that say "copy" or "write down" need the exact text for the
     report - do not paraphrase the raw-context boxes.

Cleanup
  The quest is abandonable. Abandoning it and removing the mod folder
  takes the site and the feed post with it.
