Checking your quest

Find the message that matches yours. The quest, node, address, count or date may change. This page quotes the words that stay the same and explains what to try next.

The editor checks for specific problems while you build, in some panels and when you export. These checks can catch common mistakes; a quiet editor does not prove that a quest will play well. Use a dry run and test the exported mod in the game before you share it.

Some messages appear on the canvas or under a field. Others appear beside the thing you are editing, or in the export report. The sections below explain where to find them, what they mean and what to try next.

Where messages appear

On the node
A small badge on the card, visible from across the canvas. This is how you find a problem in a quest too big to read node by node.
In the inspector
Under the field the message is about, when you have that node selected. Field messages only show while the node is selected. They cannot nag at you from the other side of the canvas.
On the canvas, as a chip
A small counter beside the canvas tools. It reads No issues or shows how many problems are blocking and how many are to review. Move your mouse over the counter to read the full messages and next steps. Red marks an item the editor counts as blocking; amber marks something to review. “Blocking” means the editor sees a serious risk, but it does not stop you from exporting.
Inside a panel
Ten further messages live in the editors themselves. They sit in the quest's Health section, the device tree, a database's tables, an addon card and the website builder. They describe the thing you are looking at, so they appear beside it rather than on the node. See messages inside a panel.
In the export report
Everything the export checks found, listed before the .zip is written. See the report.

How to read the colours and labels

On the canvas and in the inspector, amber means review this; red means the editor sees a serious risk. In the export report, blue marks a note, amber a warning and red an error. If any report item is an error, the heading says Needs attention; otherwise it says Good to know. Those headings do not lock the download button.

Read the full sentence; do not rely on colour alone. These checks have limits: for example, the red No trigger warning checks for a game event, not a story wire. Some amber export notes also matter; one can say that files will be dropped. A clean report cannot prove that the quest plays well. See Dry run for a first check, then test in game.

Messages on the canvas and in the inspector

Names and values in these examples can vary from quest to quest. Search for the stable words from the message you see; use the explanation below to decide what to do.

Unreachable

Nothing leads to this node. Wire it to the chain that should run it — nodes do nothing until something points at them.
Colour
Amber
Where
On the node, and in the canvas issue chip.
What it means
The node is on the canvas and is never run. A node only does something when another node points at it. The exception is a lifecycle node, which starts a chain by itself.
What to do
Drag a wire from the node that should run it into this node's input. That is usually the last node of your Quest start chain. If the node is left over from an idea you dropped, delete it instead.

No trigger

Nothing completes this objective. Wire a “When event” node into its trigger socket, or the player can never finish the quest.
Colour
Red
Where
On the objective, and in the canvas issue chip.
What it means
This check looks for a When event wire. It misses story wires. The game can also tick a plain objective when the story reaches it. So this warning may appear even when that route works.
What to do
Should an in-game event complete this objective? Add a When event node. Connect its When socket to the objective's Trigger socket. If a story wire should tick it, check that route in the Dry run. The warning may be a false alarm.

Dead end

One output or step has no wire. What happens next depends on the node.
Colour
Amber
Where
On the node, and in the canvas issue chip.
What it means
One route or step has no next wire. The message names the missing outcome or step. It may say Yes, No, Installed, Missing, Correct, Wrong or a step name you chose.
On App Install Check
The player stalls if the desktop check takes the unwired route. Connect that route, or send both routes to the same next step if the result does not matter.
On Ask player
An unwired Submitted, Correct, Wrong or Cancelled route has no follow-up. That is fine if the story should stop there; otherwise wire that route onward.
On a Sequence
The named step has no wire, so that step of the sequence does nothing.
On Manual input
An unwired Wrong route shows the failure message and lets the player try again. That is often the intended design for a passphrase.
What to do
Wire the named route or step if another node should follow. A Sequence still fires its other outputs; an unwired step has no follow-up. Connect that step or remove its output if you do not need it. Leave other outcomes empty only when no follow-up is intended. On Manual input, leaving the wrong-answer route empty is fine when retrying is the design.

Nothing scheduled

No time (or no full date) is set, so the timer fires the moment the story reaches it — nothing waits.
Colour
Amber
Where
On the node, and in the canvas issue chip.
What it means
The Timer has no time set, so it does not actually wait: the story carries straight on through it. That is probably not the timer you meant to build.
What to do
Set a wait in Years, Months, Weeks, Days, Hours or Minutes. Or set a full date using Year, Month and Day. Remove the node if you do not need it.

The timer has nothing to do

When the time comes, the timer has nowhere to go — the story stops there.
Colour
Amber
Where
On the node, and in the canvas issue chip.
What it means
The Timer has a time, but nothing is wired to its Out socket. When the time comes, the timer fires and the story has no next step.
What to do
Wire the Out socket to the node that should run when the time comes. Leave it unwired if the story is meant to end there.

Only runs on completion

This is wired, but it only runs after the quest is marked complete. This graph has no Complete quest node yet.
Colour
Amber
Where
On the node, and in the canvas issue chip.
What it means
You have built follow-up work on On quest complete, but the graph has no visible finish node. That path waits until something marks the quest complete.
What to do
Add Complete quest to the final story beat, or use Complete automatically or the player's Complete button from Behaviour.

Empty

Nothing is wired to “…” That is fine if you do not need it — delete the node to clear this.
Colour
Amber
Where
On the node, and in the canvas issue chip.
What it means
One of the four lifecycle nodes is on the canvas with nothing after it, so it runs and changes nothing. The message names the node in the quotes.
What to do
Wire the nodes that should run at that moment to its output. On Quest start that is usually your briefing message first. If you do not need the node, delete it and the message goes with it.

No app name

No app name, so this check can never match anything.
Colour
Amber
Where
In the inspector, under App name.
What it means
An App Install Check set to check one app has no name to look for. The game cannot report an app as installed without a name, so the Missing path runs every time. Whether that is a problem depends on the route you intended.
What to do
Type the app's name exactly as the desktop spells it. The list-saving option is separate; it does not replace this check's app name.

No machine set

No machine set — this node does nothing until it points at one.
Colour
Amber
Where
In the inspector, under Device IP or Protected IP.
What it means
A Change port or Firewall rule node has no machine to act on. The target field is blank. The editor cannot tell whether you left it empty on purpose. This node has no machine to act on until you choose one.
What to do
Type the target address token to aim it at the machine your network created. On a firewall rule, pick Random — the quest's network instead.

No network creates that machine

This is set to a machine, but no network in this quest creates one for it to act on.
Colour
Amber
Where
In the inspector, under the address field.
What it means
The address is filled in, and nothing in the quest brings a machine with that address into the world. The node points at a machine that will not exist.
What to do
Add a Create network node from World building and point this at a device in it. If you do not need the node, remove it.

Files aimed at a network that does not exist

This “Place files” node puts files on a remote device, but no network in this quest exists for that device to live on — export would drop the files.
Colour
Red
Where
In the inspector, under Device IP.
What it means
The files have nowhere to land. The project can still export, but the exported mod will not include those files at that address. The player may be missing a clue.
What to do
Add a Create network node and give it the device this node is aimed at.

Files aimed at an address nothing uses

No device in this quest uses that address, so these files would be dropped when you export.
Colour
Red
Where
In the inspector, under Device IP.
What it means
The address is typed in and matches no device your network creates. With no address at all, the editor writes No address set, so the files have nowhere to land instead. Either way, export drops the files.
What to do
Follow the message's next step. It may list addresses your quest creates, or tell you to use the same address token you gave the network.

Files aimed at a device with no account

That device has no user account, and files mount under a user's home folder — export would drop the files.
Colour
Red
Where
In the inspector, under Device IP.
What it means
The device exists, but it has no user account with a home folder for the files. Export drops them.
What to do
Add a user account to that device in your Create network node.

A question has no accepted answer

This question is set to check the answer, but no accepted answer is filled in yet.
An “Ask player” node checks the answer, but “Answer to accept” is blank.
Where
Under Answer to accept on the selected Ask player node. The export report also repeats this warning.
What it means
The node is set to compare what the player types, but there is no answer to compare it with. Every answer misses.
What to do
Fill in Answer to accept, or change Accept to Any submitted text if any answer should continue the story.

A terminal command is not a desktop app

The game does not count lynx as an app, so this check always reads Missing even when it is installed.
Where
Under App name on the selected App Install Check node.
What it means
The node checks apps on the player's desktop, not commands. The game does not count lynx as a desktop app, even when installed.
What to do
Check a desktop app instead, such as Kisscord. The game always takes the Missing path for a terminal command, even when it is installed.

A calendar date that never comes

“31 June” never arrives — June has 30 days.
Where
On the day field of a Timer set to wait for a fixed date, while that node is selected.
What it means
The full date is filled in, but that month does not have the chosen day. The timer cannot reach it.
What to do
Choose a day that exists in that month, or change the month to one that has the day you want.

Messages inside a panel

These ten messages come from panels, not canvas checks. They appear beside the item they describe. Check the nearby item in your project. Message values may name specific items.

Health flags an Objective with no event trigger

1 objective has no trigger wired in, so the player can never complete it.
Where
The Quest tab, in Health at the bottom.
What it means
The panel counts objectives without a When event wire. It does not check story wires. A plain objective can still tick when the story reaches it. This count may include an objective that works by story flow.
What to do
Should an in-game event complete this objective? Connect a When event to its Trigger socket. If a story wire should tick it, check the route in the Dry run. This panel may be counting a false alarm. See Objectives for both routes.

A router with no recognized recovery route

This router has no way in: set a model for `fern`, or enable support-mail recovery.
Where
In the device tree, under the router.
What it means
The editor checks for a router model that supports fern recovery or support-mail recovery. It cannot check every route. Review the ones you planned.
What to do
If the player should use fern, give the router a model. If they should get credentials by e-mail, switch on support-mail recovery. Test any other route in game.

An exploit that lands in the wrong account

The SSH exploit lands in a guest account when it finds one, so the player may need to switch user or crack a password to reach the accounts you wrote. Turn this off for a machine that should have only the accounts listed here.
Where
In the device tree, under a machine with the exploit enabled.
What it means
This is a reminder, not a fault. The player may enter as the guest account instead of the account that holds your files. They may need to switch accounts or find another way in.
What to do
Leave it on if switching user is part of the puzzle. Turn it off if the machine should hold only the accounts you listed.

A database table the game will skip

This table has no name, so the game will skip it.
Where
Under a table in a database editor.
What it means
The rows you typed will not exist in the game. The player will search a table that was never created.
What to do
Name the table. The rows survive as soon as it has one.

A detail missing from the editor's event list

Not one of this event's known details
Where
A small amber warning icon beside a condition's value field. Hover it for this text.
What it means
The detail you typed is not in the editor's list for this event. The condition may never match if the game does not send that detail.
What to do
Pick a detail from the list the editor offers. If the detail you need is absent, check the game's event information or choose another event. This warning compares against the editor's known details; it cannot inspect a live game event.

An addon card that runs nothing

Not set up yet — this card doesn't know which tool action it runs. Delete it and drag the action in again from the palette's “Editor Mods” group. As it stands it does nothing.
Where
On an addon card in the inspector.
What it means
The card has no tool action selected. This can happen with an incomplete or older card; it does not prove that the addon failed to load.
What to do
If the addon is not loaded, load it first. Then remove this card and drag the action in again from the palette. The existing card has no action to edit.

A required game mod may be missing

Players need the Example Pack game mod installed for this to work — say so in your quest description.
Where
On an addon card, in both the tool-response and pack-data editors.
What it means
This action depends on the named game mod. A player without that mod may not get the intended result, and the game may not explain what is missing.
What to do
Name the required game mod in your quest description. The editor cannot install it for the player.

A pack you cannot re-pick from

The Example Pack pack isn't loaded on this machine. Everything you chose here is saved in the project, so the node keeps working — load the pack again to pick a different data shape.
Where
In the pack-data editor.
What it means
Your chosen data and values stay in the project. You can still export them, but the editor cannot offer another data shape until the addon is loaded again. The player's game still needs the related game mod, when the addon requires one.
What to do
Nothing, unless you want to choose a different shape. Load the addon to change it.

A conversation that plays live

Timed conversations are sent through the game's live messaging API, one message at a time with the delays you set. Player replies, uploads and “unlocks after” steps only work in the normal declarative script, and the game does not clean live messages up with the quest. Worth an in-game check before you ship it.
Where
Under Play when the story reaches this node on a dialogue node, once it is switched on.
What it means
Live playback costs you three things. Replies stop working, uploads stop working, and the messages stay on the player's phone afterwards.
What to do
Leave it off unless you need the conversation to land on a specific beat. If you need it, test the quest in the game.

An unlisted page is missing from search

Not in search results — only a direct URL (or dirhunter) leads here.
Where
In the website builder, above the preview of an unlisted page.
What it means
The page is not in in-game search. A direct address, a link or dirhunter can still lead to it; unlisted does not mean private. The editor does not check whether another page links here.
What to do
Keep it unlisted if that fits your clue, and give the player a way to reach it. If the page should appear in search, turn on Listed in the in-game search.

The report before you export

Quest or website names can change. Match the rest of the sentence.

A quest waits for the player to claim it

The player claims this one from its Hackhub feed post — nothing in it runs until they do.
Report
Good to know — this can be an intentional way to start a quest.
What it means
The quest does not start on its own. The player must find and claim its feed post first.
What to do
Leave it this way if the player should claim the job. Turn on Start automatically if it should begin when the mod loads. The only feed post tested in game had text only. It had no poster, employer or comments. If it still fails, open the Quest tab and change Quest identifier. Use one this save has not seen.

A quest has no way to start

Nothing can start this quest. It does not start automatically and it is not advertised on the Hackhub feed.
Report
Red error.
What it means
The player has no route to claim this quest, and it does not start by itself.
What to do
Turn on Start automatically, or add a feed post so the player can claim it.

A port or firewall rule has no target

A “Change port” or “Add firewall rule” node has no device IP, so it has nothing to act on.
Report
Amber warning. The selected node also shows a field message; see No machine set.
What it means
The node has no machine to change or protect, so this instruction does nothing.
What to do
Point it at a machine created by a Create network node. The field message gives the specific choice for that node.

A network claims a domain another server may use

This network claims the domain … Domain names are shared with the whole game.
Report
Amber warning.
What it means
The domain is shared by the whole game. Another mod or the base game may already use it. Then its server can answer instead of yours.
What to do
Choose a distinctive domain connected to your story, rather than a common or placeholder name.

A network the game cannot build

… has machines behind it, but only a router or a splitter can hold other machines — those machines will not be built.
Report
Red error.
What it means
A device that cannot contain other devices has one or more machines placed behind it. Those machines will not exist in the exported game.
What to do
Change the parent device to a router or splitter, or move the child machines under one that can hold them.

Firewall rules are on the wrong device

… carries firewall rules, but only a firewall device enforces them — they will be ignored.
Report
Red error.
What it means
The rules are saved on a device that is not a firewall, so the game ignores them.
What to do
Put the rules on a Firewall device between the router and the machine you want to protect.

A login service has no account to log in as

… has a login service open but no user accounts, so the player cannot break in.
Report
Red error.
What it means
The report sees no account you added to this device. It ignores the game's built-in root and guest accounts. The warning may be wrong when those accounts are on.
What to do
Open the network's Devices. On a Device, check Add stock root and guest accounts; it is on by default. If it is off, add an account or close the port. This toggle is not on Routers, so add an account there. Test the route in game when stock accounts are on.

A version a tool will not read

… Metasploit needs three numbers (for example “OpenSSH 7.2.0”) — it rejects anything else.
Report
Red error.
What it means
The service version number is incomplete or contains a letter. Metasploit expects a three-part number, such as OpenSSH 7.2.0. The player cannot use that exploit with a different format.
What to do
Use the version reported by the machine, written as three number parts, such as OpenSSH 7.2.0.

A Lynx result points to a social profile the game cannot open

The lynx result advertises @… Searching a social handle that has no profile behind it crashes the game and corrupts the player's save.
Report
Red error.
What it means
A Tool response for Lynx can contain an @name. The editor cannot create the social profile the game needs to search for it. The warning says that search may crash the game and damage the player's save.
What to do
Remove the @name from the Lynx result. Or point the player to a website, e-mail address or IP address instead.

An Open handbook node has no article

An “Open handbook” node has no article, so it does nothing.
Report
Amber warning.
What it means
The node has nowhere to take the player.
What to do
Pick an article only if the node needs to make a handbook call. In HackHub 1.3.1, the game opens the landing page, not your chosen page. See the handbook-entry note and test this in game. Delete the node if you do not need it.

A note about Create Wi-Fi

“Create Wi-Fi” exports as a native access point in HackHub 1.3.0+.
Report
Blue information note — not an error.
What it means
Wi-Fi created here works as a native access point in HackHub 1.3.0 and later. Bettercap may show no network name if you target the access point by its hardware address. Scanning, joining and cracking still worked in that test.
What to do
No change is needed because of this note. If the displayed name matters to your quest, test that step in the game.

A replyable e-mail has no From address

… lets the player reply, but its From address is empty — a player's reply arrives addressed to your mail's From, so with no From there is nothing a trigger can match.
Report
Blue information note.
What it means
The player can reply, but the reply has no destination address that your quest can check.
What to do
Give the e-mail a From address. To react to a reply, add a When event for Mail.Sent. Check that its to field has your address.

A reply button works, but the reply does not point back to its e-mail

The mail goes out with its reply flag and the Reply button draws. The player's reply arrives addressed to your From address.
Report
Blue information note.
What it means
The game shows a Reply button, but the reply contains no reference to the message it answers. The destination is the original e-mail's From address.
What to do
Use a When event for Mail.Sent to react to a reply. Check whether its to field matches the From address. The event does not identify which e-mail the player answered.

A phone answer also registers a terminal command

Phone lines with typed answers also register a terminal command (qe-…) the player uses to answer.
Report
Blue information note.
What it means
A typed answer in a phone conversation has a command beginning qe- for the player to use.
What to do
Tell players where to find the command if the phone's answer is part of your quest. Test the call in game before relying on it.

A conversation set to play live has no wire

… a conversation is set to “play when the story reaches this node” but nothing is wired into it — it stays a normal quest conversation.
Report
Amber warning.
What it means
The conversation is set to play at a story beat, but no wire leads into its node. It stays a normal quest conversation instead of playing at that point.
What to do
Wire the node into the story if it should play at a specific moment. Otherwise change the live-play setting back to a normal quest conversation.

A live conversation skips normal reply features

A conversation set to “play when the story reaches this node” is sent live at that moment. Player replies, uploads and “unlocks after” steps are skipped.
Report
Amber warning.
What it means
Once the story reaches the wired node, the editor sends the conversation live. Replies, file uploads and steps that wait for an earlier message are skipped. The game also does not remove these live messages when the quest ends.
What to do
Use live playback only if you need the conversation at that exact story moment. Test it in game, especially if you expect replies or uploads.

An upload becomes a text message

Kisscord uploads compile to a “[uploaded file …]” message.
Report
Blue information note.
What it means
A Kisscord attachment appears as a line of text, not as a file the player can open.
What to do
If the player needs the actual file, use Place files and tell them where to find it.

Give data to an addon is not set up

A “Give data to an addon” node is not set up yet — as it stands it does nothing.
Report
Amber warning.
What it means
The node has no addon or data shape selected, so it cannot send anything.
What to do
Open the node and choose its addon pack and data shape. Delete it if you do not need it.

An addon action node is not set up

An addon node is not set up yet — add it again from the palette's Editor Mods group.
Report
Amber warning.
What it means
The node has no action selected. It will do nothing as it is.
What to do
If needed, load the pack first. Then remove this card and drag the action into the quest again from the palette's Editor Mods group. Or delete the card if you do not need it.

A quest needs a game mod for its addon data

Community data is used in this quest. It needs the game mod installed on the player's machine.
Report
Blue information note.
What it means
This quest uses community data that depends on a separate game mod. A player without that mod will not get the intended result.
What to do
Name the required game mod in your quest description so players know they need it. The editor cannot install it for them.

An unlisted page will not appear in search

Nothing links to it and the in-game search will not show it.
Report
Blue information note.
What it means
The page stays out of in-game search. The note assumes no page links to it, but the editor does not check links. A link, direct address or search with dirhunter can still reach it. Unlisted does not mean private.
What to do
Leave it unlisted when that fits your clue. Add a link or another way to find it. If the player should find it in search, turn on Listed in the in-game search.

Two pages have the same address

… has pages at the path … They ship as two definitions of the same address.
Report
Red error.
What it means
Two pages on one website use the same path, so both claim the same address.
What to do
Give one page a different path. Each page on the site needs its own address.

A page path does not start at the website root

The page … has the path …, but paths start at the host root — it should be /….
Report
Red error.
What it means
The in-game browser and dirhunter look for pages from the start of the website address.
What to do
Start the page path with /, then check the full address in the website preview.

Two websites on one domain

… is the host of … websites in this mod. Domains are global — two sites on one host will fight over which one answers.
Report
Red error.
What it means
Two websites in this mod claim the same host. The report does not inspect other installed mods, so it cannot find every possible conflict. The game may not serve the site you intended.
What to do
Give each website its own distinctive host name.

A placeholder domain ships as a real website

… is a placeholder domain, but the export ships it as a real site any player can find.
Report
Amber warning.
What it means
A sample name such as example.com or localhost will be exported as the actual website address. Another mod may already use it.
What to do
Choose a distinctive domain name that fits your story.

A Twotter handle the game will not accept

“@…” cannot be a Twotter handle: use letters, numbers and underscores, 3 to 15 characters.
Report
Red error.
What it means
The handle contains a character the game does not accept, or is too short or long. Players search for this handle, so they may never find the profile or clue.
What to do
Use 3 to 15 letters, numbers or underscores in the handle.

A Twotter account has no display name

@… has no display name. The game shows the display name on the profile and falls back to something generic without it.
Report
Blue information note.
What it means
The account still has a handle, but its profile uses a generic name instead of the name you intended.
What to do
Add a display name if players need to recognise this character. The account can still export without one.

Two Twotter accounts share a handle

Two Twotter accounts share the handle @… Handles are what players search for, so only one of them can ever be found.
Report
Red error.
What it means
The game cannot tell which account a player means when both have the same handle. Capital letters do not make two separate handles here.
What to do
Give one account a different handle.

A Twotter node has no account to post as

… the Twotter node has no account yet. / … points at a Twotter account that is not in this mod any more.
Report
Red error.
What it means
The node has no account selected, or the account it used to name has been removed. The post will not appear.
What to do
Pick an account in the node's Account field. If you need a new character, add it in the Twotter panel under Manage accounts first.

A Twotter node has nothing to post

… posts nothing — it has no tweet rows. / … has a tweet with no text and no picture.
Report
Amber warning.
What it means
The node has no posts, or one post has neither text nor a picture. A blank post is not a useful clue.
What to do
Add a post and give it text. Or delete the node if you no longer need it. Pictures do not appear in game; see the picture warning.

A Twotter post picture will not appear in game

The game's posting record has no picture field — the picture stays in your project and in the editor's preview, but players will not see it.
Report
Amber warning.
What it means
The editor keeps the picture, but the game does not show it in the timeline or on the post page. This is a game limit, not a broken upload.
What to do
Put any clue in the post's text, or place it in a file the player can open.

An older post's time changed when it was opened

… came from an older draft whose tweet time could not be carried over exactly, so it now says “1 month earlier”.
Report
Blue information note.
What it means
The editor could not preserve the older post's time exactly while opening the old project.
What to do
Open the Twotter node and set the amount and time unit to the age you intended.

Place files could not put its files on a device

A “Place files” node could not be placed — … Point it at a device this quest creates, or target the player's PC instead.
Report
Amber warning. The files are not in the exported mod where you aimed them.
What it means
The chosen device is missing, or it lacks an account with a home folder. The project may also lack a network for the device.
What to do
Point the node at a device this quest creates, add an account if needed, or choose the player's PC. The related field messages explain a missing network, an address with no device and a device with no account.

Messages about addon targets

The export report shows these amber warnings when your quest uses a loaded addon. That addon must check for target details. Not every addon has these rules. Read your message; the addon decides which services, versions and weaknesses can match.

An addon does not recognise a service

“…” on this target means nothing to this addon — its tools only understand ….
What it means
The target uses a service name this addon's tools do not recognise, so the tool will never match it.
What to do
Change the service to one named in the warning, or check the addon's own instructions.

An addon needs a service version

This target has a service but no version — the addon matches targets by their version string, so a blank version never lines up.
What it means
The quest listens for an addon that matches by version, but the service has no version filled in.
What to do
Fill in the version reported by the machine. Do not invent one; it must match what the game tool sees.

An addon is looking for a weakness the quest has not marked

This addon looks for targets with one of these weaknesses. None of this quest's targets names one.
What it means
The addon searches for the weakness types named in the warning. None of your quest's targets has one.
What to do
Mark the target with a weakness from the warning's list if that is what the game scenario uses.

An addon does not recognise the marked weakness

This quest's targets are marked …, but this addon only looks for … — none of them lines up.
What it means
The targets do have weaknesses, but not the type this addon searches for.
What to do
If the game scenario supports it, choose a weakness from the addon's list in the warning. Otherwise change the addon or quest design.
