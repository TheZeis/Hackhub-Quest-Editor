Manual illustration prototype

Five fixed scenes test a shared, locally bundled renderer before any editor figures are converted. They use the editor's default Midnight colours and system font, with a fresh First Contact example in an isolated frame.

Review checkpoint: these are frozen illustrations, not a working editor. The original 88 editor figures have not been migrated. The game-only installation image has been removed rather than replaced with an invented game screen; its surrounding tutorial instructions remain. The other five unlinked game-image names and two unlinked editor-panel names remain dormant.

1. Objective inspector

The Objective node is selected. Its name, player-facing description, hint and suggested command appear in the inspector.

2. How-to canvas with a typed wire

A When event with a search condition is wired to the Objective it completes. The wire and node cards come from the editor's canvas renderer.

3. Settings panel over the editor

The real Settings panel is open over the fixed First Contact workspace. It shows theme and typography choices, plus the canvas preferences below.

4. Full editor workspace

First Contact is open with the top bar, node library, connected quest canvas, selected Objective inspector and status bar visible.

5. Transient mid-drag state

A still illustration shows a connection being pulled from the When event toward the Objective. The loose wire is drawn as a fixed snapshot, not an active drag.
